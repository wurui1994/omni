# 节点图的类型覆盖层（typed overlay）

> 这一份是**决定与判据**，不是愿景。落地前先立住三件事：那一层收什么、谁写、怎么判。
> 上游是 ADR-0033（节点图）与 ADR-0037 §5.1a（自举尺子）；任务是 #40。

## 一、为什么现在要（两笔量出来的账）

**第一笔：三条腿各写了一份类型推断。** 同一件事在三处：

| 在哪儿 | 叫什么 | 收哪几种 |
|---|---|---|
| `backend-core.js` | `typeOf` / `elemType` / `dictOf` / `fieldType` / `multiShape` + `ctx.shapes` | `int` / `real` / `string` / `bool` · 记录形状 · 列表元素 · 字典键值 · 多值 |
| `backend-wat.js` | `kindOf` + `sc.kindOf` + `globalKinds` | `int` / `real` / `str` 三档 |
| `backend-c.js` | `dOf` / `NUM_PRIMS` | "这一格能不能当 double 直接算" |

三份的口径**已经不一样**了：core 分 `int` 与 `real`，wat 只分 `int` / `real` / `str`，
c 只问"是不是数"。它们各自都对，可**同一格节点问三次会得到三个答案** —— 这不是隐患，
是今天就在发生的重复（`retTypeOf` 一天里撞两次洞，两次都是"这一处的类型说法与别处不一致"）。

**第二笔：尺子上剩下的墙有一多半在等它。** ADR-0037 §5.1a 那张按族的账（2026-09-18）：

- 跨文件才知道的事 **544 / 33.1%** —— "别的文件里那个名字是什么类型"
- 类型层的算子 **149 / 9.1%** —— `typeof` / `sizeof` / `x.(T)` / `T is $struct`
- 类型才分得开的事 **121 / 7.4%** —— 内嵌字段 · 泛型实例化 · 两个类型的同名方法
- 编译期求值里的 `$for` **71** —— 遍历 struct 的字段列表，每一趟的 field 名字与类型都不同

四项加起来 885 份 / 54%。**映射那一层已经到底了**：这些不是"哪一格没接"，
是"这一层看不见类型"。

## 二、决定一：那一层收**节点 -> 类型**（不是名字 -> 类型）

理由三条，都能立刻验证：

1. 图是 **DAG**，一格节点可能被共享（`tests/graph/stat.js` 的"共享一次"判着）——
   一格节点只有一个类型，按节点存是唯一自洽的存法；
2. 名字答不了"这格表达式是什么类型"：`f(x) + 1` 里那格 `call` 没有名字；
3. core 的 `typeOf(x, env, ctx)` **本来就是按节点问的**，只是把环境当参数传 ——
   抽出来就是这一层，不是新发明。

**类型的词汇只收"图这一层分得开的那几种"**（与 core 今天在用的对齐，一格不多）：

```
标量   int · real · string · bool · nil
聚合   list T · dict K V · record { 字段名 -> 类型 }（字段名静态可知那一种，见 shape.js）
函数   fn (T…) -> T
多值   values (T…)
不知道 unknown        ← **这一格是决定的核心，见第四节**
```

**不收具名类型**（`ast.Ident` / `Box` / `IfBuilder`）。具名类型是那门语言的事：
覆盖层只认"它长什么样"（record 的字段表），不认"它叫什么"。
继承 / 接口 / 泛型实例化一律不收 —— 那几样在 `hints` 里给什么就是什么（第三节）。

## 三、决定二：**一趟单独的推断**，种子由映射交

推断放 `src/core/graph/types.js`，输入是**一张图**，输出是 `Map<节点, 类型>`。

**为什么不让映射填**：十一门语言各填一遍就是十一份重复 —— 那正是这一份要消掉的东西。
推断能用的东西图上都有：`const` 的字面量、`conv` 的 `to`、`record-new` 的 `names`、
`func` 的 `params`、内建表里那几格固定类型（`primFixedType` 已经在了）。

**但有一格必须由映射交**：语言知道而图上看不出的那几样 —— 具名类型的字段表
（映射里的 `STRUCTS`）、方法的接收者类型（`METHODS`）、装 map 的那些名字（`MAPS`）。
这一格走 `opts.hints`：映射交一张表，推断那一趟拿它当**种子**。

规矩一条：**推断不猜跨文件的东西**。种子里没有的，就是 `unknown` ——
而 `unknown` 不是"以后再说"，见下一节。

## 四、决定三：怎么判（三条判据，先写后做）

**判据一 · 三处必须说同一句话**（`tests/graph/types.js`，新）。
对每份语言例子跑推断，再与两条腿各自的答案逐格比：core 的 `typeOf` 与 wat 的 `kindOf`
说的必须与覆盖层**一致**（wat 那三档是覆盖层的粗化：`int`->int、`real`->real、
`string`->str，别的档比不了就不比）。不一致就是有一处错 —— 这一条把"三份重复"变成
"一份 + 两份核对"，而且它**今天就能跑**（不必等覆盖层被谁用上）。

**判据二 · 整层可删**（`tests/graph/delete.js` 那条纪律的延长线）。
把覆盖层整格摘掉，**六条腿必须照旧跑，只是回到今天的形状账**。
它是"覆盖层"而不是新的必需层 —— 这一条就是那个词的定义。

**判据三 · 不许猜（这一层最大的风险）**。
今天 core 里有 **9 处** `?? 'int'`（数出来的：字面量 · const · ref · 调用的返回 ·
下标的元素 · pick 的第 k 格 · 形参 · 返回值）—— 查不到就当 int。那是**猜**，而且已经咬过两次
（`retTypeOf` 把串接说成 int、把 match 说成 int，两次都是方言当场骂一句错误而不是
一格有名有姓的缺口）。覆盖层落地时那几处要改成：**问覆盖层，答 `unknown` 就报缺口**。

所以判据三是一句可执行的话：**`unknown` 不许被默认值吞掉**。
落地时 `tests/graph/types.js` 里要有一格反向证物 —— 一份故意推不出来的图，
它必须报缺口，而不是印出一个答案。

## 五、边界（不做什么）

* **不做类型检查**。这一层只答"这格是什么"，不答"这格对不对"。
  报错仍旧归各条腿（方言的类型器、wasm 的校验器）——覆盖层只是让它们**问同一个地方**。
* **不动代数**：28 格节点 + 25 格内建一格不加不减（ADR-0033 §2.3 那条判据不变）。
  覆盖层是**旁边一张表**，不是节点上的新附属 —— 这样 `delete.js` / `shrink.js` /
  `iface.js` 那几条判据一条都不用改。
* **不收语言的类型系统**。具名类型、接口、泛型、生命期都不进这一层；
  它们经 `hints` 落成"长什么样"，落不成的就是 `unknown`。

## 六、落地次序（一步一量，每步都能停）

1. **抽**：把 core 的 `typeOf` 那一套原样搬进 `types.js`，core 改成调它 ——
   **产出必须逐字节相同**（`tests/graph/run.js` 的 core 那一栏一格不许动）。零风险，先消一份重复。
2. **判**：写 `tests/graph/types.js`（判据一 + 判据三的反向证物）。
3. **核**：让 wat 的 `kindOf` 也问它，两处答案对不上就当场红。
4. **喂**：给映射加 `hints`（`STRUCTS` / `METHODS` / `MAPS` 三张现成的表），
   量一次尺子 —— 这一步才可能动那 885 份的账。
5. **用**：`x.(T)` / `T is $struct` / `$for` 那几族按覆盖层落地，各带判据。

前三步不碰语料、不动分子，是纯粹的"把三份重复变成一份"；第四步起才动尺子。
