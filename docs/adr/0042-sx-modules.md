# ADR-0042 核心方言要有模块 —— weak 那套机制作废

日期 2026-09-21 · 状态 已定方向，分刀落地

## 结论先写

**weak 是无效设计，要彻底改掉。** 它不是"一格可以优化的实现"，它是**缺模块**逼出来的
变通：核心方言（`.sx`）今天只有 `(module NAME …)` 这一个壳，**没有 import、没有 export**
（`sexpr/lower.js:494` 与 `:3238` 那两处是唯一认得 `module` 的地方，认的只是"最外面包了一层"）。

于是共享的东西（数组工厂、helper、模板展开出来的那些）只能**谁用谁发一份**，靠链接期
"弱定义、重复取一个"收场。后果一路长出来：

- 复用一份产物时那些 weak 项得有人生 → 于是有 `.wk`（把正文存盘，还要闭包到不动点，
  `frontend-asy/link.js:312`）；
- 复用时它引到的模块得跟着进来 → 于是有 `.dep`（`link.js:109`）；
- 链接器要收下弱未定义、把 `bl` 改 `nop`（`link/flat_image.js:119`、`elf_exe.js:1588`）——
  那正是 `docs/design/build-system.md` §0 约束 2 说的"不许 weak"。

TypeScript 不是这样做的：一个声明**只存在一次**，别的单元 `import` 它；跨单元要看的是
`.d.ts`（接口），不是把实现复制一遍。Rust 的 `.rmeta`、Go 的 export data 同理。

## 要加的东西（核心方言这一层）

```
(module NAME
  (import M (n1 n2 …))      ; 把另一格单元的导出名绑进本单元的作用域
  (export n1 n2 …)          ; 本单元对外可见的名字
  decls…)
```

三条规矩，缺一条就退回今天的样子：

1. **一个声明只有一个家**。`asy` 那侧其实已经算得出这一格 —— `OMNI_ASY_FP=1` 印的
   "asy 归属"就是每个名字属于哪个单元（cli.js 那段 `r.owners`）。归属在，就不必复制。
2. **import 是名字绑定，不是文本拼接**。今天的链接模型是"整棵 import 树摊成一个 Program、
   模块级名字全程序唯一"（ADR-0016）—— 那条要留着当**发射期**的模型，但方言这一层得先有
   边界，否则摊平之前没人知道谁是谁的。
3. **导出面是算出来的，不是手写的**：`export` 由"被别的单元 import 到的名字"闭包算出，
   落成一份**接口**（`.sx` 的一段，不是第四种 ad-hoc 格式）。

## weak 怎么死

- 共享 helper：从"每个用到的单元各发一份 weak"改成"**归属单元发一份 + 别人 import**"。
- 模板/泛型展开：展开产物归**实例化点所在单元**，跨单元同一实例按内容哈希去重（内容寻址，
  与 `modcache` 的键同一条规矩）—— 重复的是同一份内容，于是 import 得到同一格。
- 链接器那两处"弱未定义就 nop"：改成**缺了就报**（谁要它、哪条边），与约束 2 一致。

## 顺带被收掉的四个后缀

`.wk` 与 `.dep` 随 weak 一起消失（前者是 weak 的正文，后者是"复用要带哪些"——
有 import 之后这就是模块图本身）。`.sec` / `.aif` 合成**一份模块接口**，它属于模块，
不属于缓存：缓存只负责"这份接口还新不新"（`build/modcache.js` 的键 + 索引）。

## 落地次序与判据

1. **方言加 import/export**（只解析 + 检查，不改发射）：`(import …)`/`(export …)` 进
   `sexpr/lower.js`，未导出的名字被 import 时报人话。
   *判据*：`tests/sexpr` 全绿 + 新增用例（import 未导出的名字要报、循环 import 要报整条链）。
2. **接口落成 `.sx` 的一段**：`.sec`/`.aif` 改写成 `(module … (export …) (sig …)…)`，
   读的那侧（`frontend-asy/iface.js`、`modules.js`）跟着换。
   *判据*：asy 那批例子 EPS 逐字节不变、重编计数不变。
3. **weak 退场**：asy 的 `owners` 接上"归属单元发一份"，`.wk` 停写；链接器弱未定义改成报错。
   *判据*：`tests/asy` 全绿；故意删一个 helper 时报的是"谁要它"而不是静默 nop。
4. **摊平那一步留在发射期**（ADR-0016 不变）：方言有边界之后，摊平只是一次确定的重命名。

每步都能单独验，而且 1 与 2 不碰 weak —— 所以顺序不能颠。
