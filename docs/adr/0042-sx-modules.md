# ADR-0042 核心方言要有模块 —— weak 那套机制作废

日期 2026-09-21 · 状态 已定方向，分刀落地

## 结论先写

**weak 是无效设计，要彻底改掉。** 它不是"一格可以优化的实现"，它是**缺模块**逼出来的
变通：核心方言（`.sx`）今天只有 `(module NAME …)` 这一个壳，**没有 import、没有 export**
（`sexpr/lower.js:494` 与 `:3238` 那两处是唯一认得 `module` 的地方，认的只是"最外面包了一层"）。

于是共享的东西（数组工厂、helper、模板展开出来的那些）只能**谁用谁发一份**，靠链接期
"弱定义、重复取一个"收场。后果一路长出来：

- 复用一份产物时那些 weak 项得有人生 → 于是有 `.wk`（把正文存盘，还要闭包到不动点，
  `frontend-asy/link.js:312`）；
- 复用时它引到的模块得跟着进来 → 于是有 `.dep`（`link.js:109`）；
- 链接器要收下弱未定义、把 `bl` 改 `nop`（`link/flat_image.js:119`、`elf_exe.js:1588`）——
  那正是 `docs/design/build-system.md` §0 约束 2 说的"不许 weak"。

TypeScript 不是这样做的：一个声明**只存在一次**，别的单元 `import` 它；跨单元要看的是
`.d.ts`（接口），不是把实现复制一遍。Rust 的 `.rmeta`、Go 的 export data 同理。

## 要加的东西（核心方言这一层）

```
(module NAME
  (import M (n1 n2 …))      ; 把另一格单元的导出名绑进本单元的作用域
  (export n1 n2 …)          ; 本单元对外可见的名字
  decls…)
```

三条规矩，缺一条就退回今天的样子：

1. **一个声明只有一个家**。`asy` 那侧其实已经算得出这一格 —— `OMNI_ASY_FP=1` 印的
   "asy 归属"就是每个名字属于哪个单元（cli.js 那段 `r.owners`）。归属在，就不必复制。
2. **import 是名字绑定，不是文本拼接**。今天的链接模型是"整棵 import 树摊成一个 Program、
   模块级名字全程序唯一"（ADR-0016）—— 那条要留着当**发射期**的模型，但方言这一层得先有
   边界，否则摊平之前没人知道谁是谁的。
3. **导出面是算出来的，不是手写的**：`export` 由"被别的单元 import 到的名字"闭包算出，
   落成一份**接口**（`.sx` 的一段，不是第四种 ad-hoc 格式）。

## weak 怎么死

- 共享 helper：从"每个用到的单元各发一份 weak"改成"**归属单元发一份 + 别人 import**"。
- 模板/泛型展开：展开产物归**实例化点所在单元**，跨单元同一实例按内容哈希去重（内容寻址，
  与 `modcache` 的键同一条规矩）—— 重复的是同一份内容，于是 import 得到同一格。
- 链接器那两处"弱未定义就 nop"：改成**缺了就报**（谁要它、哪条边），与约束 2 一致。

## 顺带被收掉的四个后缀

`.wk` 与 `.dep` 随 weak 一起消失（前者是 weak 的正文，后者是"复用要带哪些"——
有 import 之后这就是模块图本身）。`.sec` / `.aif` 合成**一份模块接口**，它属于模块，
不属于缓存：缓存只负责"这份接口还新不新"（`build/modcache.js` 的键 + 索引）。

## 落地次序与判据

1. **方言加 import/export**（只解析 + 检查，不改发射）：`(import …)`/`(export …)` 进
   `sexpr/lower.js`，未导出的名字被 import 时报人话。
   *判据*：`tests/sexpr` 全绿 + 新增用例（import 未导出的名字要报、循环 import 要报整条链）。
2. **接口落成 `.sx` 的一段**：`.sec`/`.aif` 改写成 `(module … (export …) (sig …)…)`，
   读的那侧（`frontend-asy/iface.js`、`modules.js`）跟着换。
   *判据*：asy 那批例子 EPS 逐字节不变、重编计数不变。
3. **weak 退场**：asy 的 `owners` 接上"归属单元发一份"，`.wk` 停写；链接器弱未定义改成报错。
   *判据*：`tests/asy` 全绿；故意删一个 helper 时报的是"谁要它"而不是静默 nop。
4. **摊平那一步留在发射期**（ADR-0016 不变）：方言有边界之后，摊平只是一次确定的重命名。

每步都能单独验，而且 1 与 2 不碰 weak —— 所以顺序不能颠。

## 进度与下一刀的缝（2026-09-21）

**第 1 步已落地**（`sexpr/lower.js` 的 `resolveModules`）：一份文本里几个 `(module 名字 …)`，
`import`/`export` 六条检查各报人话（`tests/sexpr/modules.js` 7/7 + `cases/52-modules.sx`），
发射一行没动。顺带修掉 `tests/sexpr` 的 16 个假红（没有 `llvm-config` 时那条腿现在**跳过
并说明**，`tests/lib/legs.js`）——判据不可用的时候，后面每一步都无从验证，所以那一格先修。

**asy 那条轴的判据确认可用**：它留的也是 `run` + `run-llvm`，跳过 llvm 之后 `run` 这条腿
仍然对账真 asy 的 EPS（`node tests/asy/run.js 01-arith 02-strings` → 2/2，1.0s）。
于是第 2 步有便宜判据：挑三五个例子冷热各跑一趟，比 EPS 与重编计数。

**第 2 步的缝在哪儿（下一刀要先解的一格）**：`asyModsSkip` 的 `load(nm)` 现在是**逐字段**
核 `.stamp`（每格 `路径:mtime:len:h哈希` 单独看文件还在不在、内容变没变）。换成 `modcache`
的一格键之后，跳过那一刻要能算出同一个键 —— 而键里有"依赖的内容哈希"，跳过时手上只有
`.dep` 里的**单元名**，拿不到它们的源文件路径（那在 `keyOfName` 里，是这一趟解析出来的）。
两条出路，选哪条要先量：
  a. `.dep` 里连源文件路径一起记（多一格字段，跳过时就自足）；
  b. 索引里直接记"这个单元上一趟的键"，跳过时**不重算**、只比"它依赖的那些单元的键有没有变"
     （键的闭包在索引里，与 `staleUnits` 的算法一致）。
b 更接近 `modcache` 现在的形状（`staleUnits` 已经把"上游的键进下游的键"做完了），
但它要求索引里存全部单元的键 —— 那正是 `Index` 的样子。**按 b 做，格式与算法定死如下**。

### 索引的一行（`asy-mods/index.log`，替掉 `.stamp` 与 `.dep`）

```
名字 \t 键 \t 自己的源文件 \t include1,include2,… \t 依赖单元1,依赖单元2,…
```

**`include` 那一格非有不可**（这是上一轮差点漏掉的坑）：跳过那一刻要能**自足地**重算键，
而 include 摊进来的文件既不是这个单元的源文件、也不在依赖单元里。今天 `.stamp` 是把它们
逐格记下的；索引里少这一格，改 `base/plain_picture.asy` 而 `plain.asy` 没动时就会**静默复用
旧代码** —— `asyModsBuild` 那段注释记着这个 bug 当年的样子（探针一声不响）。

依赖单元那一格顺带把 `.dep` 的 `need|` 收进来（cli 靠它把"只剩产物"的模块一并交进来，
`frontend-asy/link.js:109`），所以 `.dep` 可以停写。

### 新不新怎么判（递归，与 `staleUnits` 同一条规矩）

```
fresh(n):
  行 = 索引[n]；没有 -> 不新
  自己的键 = hash(编译器印记, 内容哈希(行.自己), 内容哈希(行.include…), main标记?)
  对每个 d ∈ 行.依赖: 若 !fresh(d) -> 不新；否则把 索引[d].键 掺进自己的键
  新 = (自己的键 == 行.键)
```

一趟里 memo 一下（同一个单元不重算）。**上游的键进下游的键**，于是"依赖变了"与"自己变了"
是同一种表示 —— 这正是 `build/modcache.js` 的 `staleUnits` 已经做完的事，asy 这侧只要把
`self` / `deps` / `extra` 三样喂进去。

### 再收一格：行里存**依赖的源文件**，不是依赖的键

读完 `asyModsSkip.load()`（cli.js:1869）之后改一处规格：今天 `stampOf` 掺进去的是
**依赖单元的源文件**（`fstamp(keyOfName.get(d))`），不是依赖的键 —— 传递性靠 `need` 那条
链在跳过时逐个 `load` 兜住。所以索引行里要存的是**依赖的源文件路径**：

```
名字 \t 键 \t 自己的源文件 \t include… \t 依赖的源文件… \t 依赖单元名… \t main标记(0/1)
```

这样跳过那一刻能**自足地**重算出与今天**同一个输入集**的键（只是从一串字段变成一格哈希），
行为不变、文件从三种变一种。若改成"掺依赖的键"，失效语义就变了（变成真·传递闭包）——
那是另一刀，要单独量，不能和"去掉 .stamp"混在一起做。

`main标记` 那一格记的是"这一份的正文里出现过主文件的基名"（今天是 `.stamp` 里有没有
`main:` 那一格）：是 1 就把当前的 `mainTag` 掺进键，于是换了入口这一份不复用；是 0 就
一格都不掺，库那几份跨入口共用。

### `.stamp` 的第三、第四个消费方（读了 cli.js:2156 与 2207 之后补的）

先前写着"这一步只动 `.stamp`（它是手写的第二份脏判定，与模块无关）"。**那句话不准**：
`.stamp` 还被**快路的清单**用着，一共四处，动它就得四处一起动：

1. `asyModsSkip.load()`（cli.js:1869）—— 逐字段核（这一格是本来就要换的）。
2. `mrec(nm)`（cli.js:2156）—— 从 `.stamp` 里**抠出 `main:` 那一格**写进清单
   `main-<入口>.dep`（第一百〇四刀：库产物跨入口共用，带主文件名的那几份换入口会被盖掉）。
3. `w|` 那一格（cli.js:2171）—— 把 `omni_weak.stamp` 的**整段文本**塞进清单
   （它的内容由整个程序决定，名字却固定；量到过 `tri` / `curve` / `tri` 第三趟拿错 weak）。
4. `asyModsFast`（cli.js:2207）—— 读清单、逐格比 2 与 3 那两样；**对上就整个前端一步不走**。

所以第 2 步的真实范围是"索引替掉 `.stamp`，同时把清单里那两格改成从索引取"。
四处任何一处漏改，症状都是**静默复用旧产物**（这三个 bug 的现场都记在那几段注释里：
label3/gamma3 在 `$alen` 上炸、`tri`/`curve` 拿错 weak、plain_picture 的探针一声不响）。

**先做第 0 步：把 `.stamp` 的读法收成一处。** 现在 `load` / `mrec` / `w|` 各自 `split('|')`
自己解析同一种文本 —— 三处解析一种格式，换格式必漏。先抽出 `stampRead(dir, name)`
（回 `{cs, fields, mainTag}`）让四处都走它，判据是"asy 冷热两趟 EPS 与计数不变"；
这一步是纯重构、零语义变化。然后第 2 步才只剩"换一处实现"。

### 这一刀的判据（便宜的那份）

挑三五个例子：`node tests/asy/run.js 01-arith 02-strings 03-…`，**冷**（清 `asy-mods`）
与**热**各跑一趟，比两样：EPS 逐字节相同、第二趟的重编计数为 0。再故意 `touch`
一个 include 进去的文件（`src/lib/asy/base/plain_picture.asy` 那种），要它**真的重编**
而不是复用 —— 那一条正是索引里 include 那一格的判据。

## 第 2 步已落地（2026-09-21）：一份 `index.log` 替掉 N 个 `.stamp`

落的是**保语义的那一版**：印记那段文本一个字节都没改，只是从「一份产物旁边一个
`.stamp`」搬进「整个目录一份 `index.log`，一行 `产物名 \t 印记`」。上面那套"按内容哈希
算一格键"留着单独做 —— 它会改失效语义，而这一步不改；两件事混在一起就没法分别量。

- 读法只剩 `stampRead`（第 0 步铺好的），它现在从**读一次的那张表**取，不再 stat N 个小文件。
- 写法收成 `stampWrite` + 末尾一次 `stampFlush`。半路崩了的后果是索引少几格、
  下一趟把那几份重编 —— 往"多编一次"那边倒，不会复用错的。
- 旧缓存不作废：目录里没有 `index.log` 而有 `.stamp` 时**先搬进来再删掉**
  （量出来：6 份搬家，那一趟照旧是复用，没有白重编一棵库）。

### 顺手补上的一格：快路上 include 从前没人问

`asyModsFast` 原先每行只核 `fstamp(u.key)`（这一份自己那个源文件），而 include 摊进来的
那几个文件只在**慢路**的印记里。于是 `base/plain_picture.asy` 改了、`plain.asy` 没动时：
慢路会重编，可快路先命中、整个前端一步不走 —— 盘上那份旧代码照旧被跑。上面第 105 行
那条规矩要求两条路问同一件事，所以快路也改成问**这一份完整的印记**（`stampInputsOk`），
清单里那格源文件只留着当人看的信息。

同时修掉一格误判：判"哪一格是文件"从前看 `startsWith('t')`，而印记里的路径可以是相对的
（`tests/asy/cases/01-arith.asy:…` 就是），那样一个真文件会被当成"按文本哈希记的那种"。
现在按"里头有没有冒号"判。

### 另一件必须记下来的（这一趟撞见的）

`.omni-cache/epsref` 里那些 oracle **被 `omni cache gc` 清掉了**。那不是产物缓存 ——
它是判据本身：重做一遍要跑近 200 次真 asy（量过 5 分多钟），而 `eps.js` 默认
**不生成**（要 `OMNI_EPS_GEN=1`），所以清掉之后这一轴只会安静地报"没有参考、不计分"。
下一刀：`cache gc` 要把 oracle 这一类保住，或者把它挪出缓存目录。
